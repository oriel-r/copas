# AI Extraction Pipeline

```mermaid
sequenceDiagram
    autonumber

    actor pas as PAS
    participant client as client
    participant api as api
    participant R2 as R2
    participant ai as queue: ai
    participant extractor as extractor
    participant ocr as Mistral OCR
    participant llm as Workers AI (LLM)
    participant air as queue: ai-result
    participant db as DB (D1)

    pas->>client: Select document (PDF)
    client->>api: POST /policies/upload-url { filename, contentType }
    api-->>client: 200 { uploadUrl, policyAssetKey }
    client->>R2: PUT policyAssetKey
    R2-->>client: 200 OK

    R2-)api: object-create { bucket, key, eTag }
    api->>db: INSERT ai_extraction_results (status: pending, policyAssetKey) -> aiExtractionResultId
    db-->>api: ok
    api->>R2: Generate temporary read URL (5 min TTL)
    R2-->>api: documentUrl (presigned)
    api-)ai: Envelope { type, payload: { aiExtractionResultId, documentUrl }, metadata: { organizationId, idempotencyKey } }

    ai->>extractor: Consume { aiExtractionResultId, documentUrl }
    extractor->>ocr: Process document (documentUrl)
    ocr-->>extractor: markdownText
    extractor->>llm: Normalize markdownText (JSON Schema)
    llm-->>extractor: structuredPayload

    extractor-)air: Envelope { type, payload: { aiExtractionResultId, structuredPayload }, metadata }
    air->>api: Consume result
    api->>db: UPDATE ai_extraction_results (id: aiExtractionResultId, status: on_review, result)
    api->>db: INSERT policies + related entities
    db-->>api: commit
```

## Rules

- Queues `ai` (api → extractor) and `ai-result` (extractor → api). See [Queues](/infra/queues.md).
- Messages use the [envelope](/infra/queues.md):
  - Queue `ai` carries `{ aiExtractionResultId, documentUrl }` where `documentUrl` is a signed temporary URL (5 min TTL) generated by `api`. Never binaries.
  - Queue `ai-result` carries `{ aiExtractionResultId, structuredPayload }`.
- `extractor` is a stateless adapter: it does not fetch from R2 directly; it delegates file retrieval to Mistral OCR via the temporary `documentUrl`, receives Markdown, and normalizes it using Workers AI (LLM).
- `api` is the only domain writer; `extractor` does not write to D1. See [Worker Boundaries](/infra/worker-boundaries.md).
- The policy is created only after the result arrives (`on_review`).
